# SCALC
Stack Based Calculator written with ISO C90 (ANSI C) using RPN.

# Usage

``` 
Commands:
  c: clear the whole stack
  P: print and pop from the Top of the Stack
  p: print the Top of the Stack
  e: evaluate the Top of the Stack
  E: evaluate, print and pop the Top of the Stack
  q: quit
  help: print a help message like this one

Push a number to the stack by typing it into the prompt.
You can perform Operations with elements of the\ntop of the Stack by using Operators.
Operators:
  '+' / 'add': add the top two Numbers of the Stack
  '-' / 'sub': subtract the top most Number from the Stack from the second Number in the Stack
  '*' / 'mul': multiply the top two Numbers of the Stack
  '/' / 'div': divide the top most Number from the Stack by the Second number in the Stack
  '%' / 'mod': get the Modulo from the top two Numbers of the Stack
  'v/' / 'sqrt': get the square Root of the top most Number of the Stack

```
